PathSense Mobile App
1. Back up the existing CEP-/src folder.
2. Copy this ZIP src folder into CEP- and replace the old src folder.
3. Run: npm.cmd install leaflet
4. Run: npm.cmd run dev
5. Test on Chrome Android over HTTPS (phone GPS/microphone/camera require secure origin).
The map uses OpenStreetMap tiles and is shown inside the app. Tap map to choose a point; spoken direction is straight-line orientation only, NOT pedestrian route guidance. SOS opens dialer/SMS and requires user confirmation.
